くらし・お金

家計や制度にかかわる計算。根拠と確認日つき。

  • 住宅ローン 返済シミュレーター

    変動金利の上昇と繰上返済（期間短縮・返済額軽減）を組み合わせて試算。5年ルール・125%ルールにも対応。

  • 家電の電気代・節約額シミュレーター

    家電を選ぶだけで月・年の電気代の目安。買い替えは何年で元が取れるか、使い方の見直しで年いくら浮くかも試算。

  • 社会保険 加入チェッカー

    パート・アルバイトの方が、社会保険の加入対象かを質問に答えるだけで確認。2026年10月の「106万円の壁」撤廃に対応。

  • 制度の計算機

    税・給付・教育の制度を、法令と公表資料で計算。途中の計算もすべて表示。

しごと・べんり

集まりの準備や、ちょっとした作業をすばやく。

  • 日程調整 候補日ジェネレーター

    期間と曜日を選ぶだけで、祝日を外した候補日と、フォーム・メール・LINEに貼る文面を作成。2段階調整にも対応。

  • 傾斜割り勘・飲み会の清算

    上司・若手の係数、幹事0円、2次会の合算、100円単位の集金に対応。結果はそのままLINEで送れます。

  • 大人数ビンゴ抽選

    大画面・読み上げ・効果音で抽選。カードを最大 200 枚印刷し、カード番号で当たりを照合。会場の Wi-Fi が無くても動きます。
    • 抽選する
    • カードを作って印刷する

  • 席替え・席順くじ

    教室の席替えと宴会の席決め。前回と同じ席・となりを避ける、固定席、前の席、隣にしない組。座席表を印刷。名前は番号だけでも。

  • 旅のしおりメーカー

    登録不要・印刷無料。行程に移動時間、持ち物、宿、予算と立て替え精算まで。A4 と A5 冊子で印刷・PDF 保存。割り勘ツールとも連携。

  • ルーレット・くじ引き

    候補を入れてスタートを押すだけ。複数選択・重み付け・シャッフルに対応。お題・サイコロも。

  • あみだくじ

    偏らないあみだくじを作って、線をたどる・全員の結果・A4 印刷。共有リンクで同じくじ。

  • Markdown＋Mermaid ビューア

    ダウンロードしてダブルクリックで使える、インストール不要・通信なしの Markdown ビューア。Mermaid の図、HTML 書き出し、Excel の表の貼り付けに対応。

  • PAC ファイル テスター

    PAC ファイルを URL 一覧で一括評価。構文チェック、ルールの隠れ検出、新旧の差分に対応。ダウンロードして使え、PAC の中身は外に出ません。

  • ADSearch（PowerShell ライブラリ）

    RSAT なしで、一般のドメインユーザーのまま Active Directory・DNS・GPO・Exchange の情報を取得。Get-ADUser などと同じ書き方で、すべて読み取り専用。

  • FILETIME・LDAP タイムスタンプ変換

    AD の pwdLastSet・lastLogonTimestamp・accountExpires などの 18 桁の数字を日時に。Get-ADUser の出力をまとめて変換。

  • 元号・西暦・年齢の変換

    昭和・平成・令和と西暦の変換、満年齢・学年・早生まれ。年齢早見表・学年早見表を印刷、履歴書の学歴の年月。

  • 当番表・グループ分け

    担当できない日と祝日を外して公平に回す当番表。男女・別の班などの条件つきのグループ分け。A4 で印刷。
    • 当番表
    • グループ分け

  • Fitbit データ CSV 変換

    Google Health（旧 Fitbit）の書き出し zip を、日ごとの表（CSV）と Markdown に。ファイルは端末の外に出ません。

まなび・あそび

こどもといっしょに、音や星や地図で。

  • ふりがなメーカー

    貼った文に、学年に合わせてふりがなを自動で振ります。自信のない読みには印、タップで直せます。A4 で印刷・Word 用にコピー。文は外に送りません。

  • 学習プリントメーカー

    たし算・ひき算（くり上がり）、九九、百ます、時計、ひらがな・カタカナ、学年別の漢字、ローマ字、迷路。名前入り・答えつき、毎回ちがう問題を印刷。
    • 九九ゲーム
    • ローマ字タイピング
    • おでかけ冊子

  • ほしぞらさんぽ（Webプラネタリウム）

    今夜の星空と月・惑星を天文計算で再現。星座をタップすると神話が読めます。ひらがなモードでこどもといっしょに。
    • 星座早見盤を作る

  • こども都道府県クイズ

    日本地図をタッチして47都道府県をおぼえよう。ひらがな・ふりがな・漢字と読み上げ。県庁所在地や名物・名所のクイズも。

  • メトロノーム

    BPM を決めて再生を押すだけ。変則拍子・アクセント・裏拍に対応し、オフラインでも使えます。

  • ブラウザピアノ

    スマホを横にすると画面いっぱいの鍵盤。指で和音、パソコンのキーボードでも弾けます。オフライン可。

  • クイズ広場

    元素記号・歴史年号・世界の首都・百人一首の決まり字を 4 択や入力で。百人一首の読み上げも。苦手だけ出し直し、ちょうせんリンク、問題と答えを印刷。
    • 元素記号
    • 歴史年号
    • 世界の首都
    • 百人一首 読み上げ
    • 決まり字
    • 早押しボタン

    内申点（都府県の令和9年度の要綱）・偏差値・出席日数の計算と、宿題タイマー・あと何日。
