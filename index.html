くらし・お金

家計や制度の計算。根拠と確認日つき。

  • 住宅ローン 返済シミュレーター

    金利の上昇と繰上返済を組み合わせて試算します。

  • 家電の電気代・節約額

    買い替えで何年で元が取れるかを試算します。

  • 社会保険 加入チェッカー

    パートの方が加入対象かを質問で確かめます。

  • 制度の計算機

    年末調整・住民税・育休の給付金などの計算。

  • 元号・西暦・年齢の変換

    和暦と西暦、年齢・学年・厄年・回忌の早見表。

集まり・イベント

集まりの準備と当日の進行に。

  • 日程調整 候補日

    祝日を外した候補日と、送る文面を作ります。

  • 傾斜割り勘・清算

    係数つきの割り勘を LINE で送れる形にします。

  • 大人数ビンゴ抽選

    大画面の抽選と、カード 200 枚までの印刷。

  • 席替え・席順くじ

    前回と同じ席を避けて決め、座席表を印刷します。

  • 旅のしおりメーカー

    行程・持ち物・予算をまとめて A4・A5 で印刷。

  • ルーレット・くじ引き

    ルーレットに、あみだくじ・お題・サイコロも。

  • 当番表・グループ分け

    条件つきで公平に回す当番表と班分け。

情シス・IT

Windows と Active Directory の仕事に。

  • PAC ファイル テスター

    PAC を URL 一覧で一括評価し、新旧を比べます。

  • ADSearch（PowerShell）

    RSAT なしで AD・DNS・GPO を読み取ります。

  • FILETIME・LDAP 時刻の変換

    pwdLastSet などの 18 桁の数字を日時にします。

変換・データ

ファイルを端末の中だけで変換します。

  • Markdown＋Mermaid ビューア

    ダウンロードして通信なしで読めるビューア。

  • Fitbit データ CSV 変換

    書き出しの zip を日ごとの CSV にします。

まなび・あそび

こどもといっしょに、音や星や地図で。

  • ふりがなメーカー

    学年に合わせてふりがなを振り、印刷します。

  • 学習プリントメーカー

    計算・九九・漢字・ローマ字などを毎回ちがう問題で。暗号づくりも。

  • ほしぞらさんぽ

    今夜の星空と星座の神話、星座早見盤づくり。

  • こども都道府県クイズ

    日本地図をタッチして 47 都道府県をおぼえます。

  • メトロノーム・ピアノ

    変則拍子のメトロノームと、ブラウザのピアノ。

  • クイズ広場

    元素記号・年号・首都・国旗・百人一首と早押しボタン。

  • 学校の計算機

    内申点・偏差値・出席日数と宿題タイマー。

  • アンプラグド・プログラミング

    ロボットの盤面と命令カードを印刷します。

  • ためして（耳・反射・目）

    高い音・反射神経・動体視力・記憶力の目安。

親・家族のために（広告なし）

親に印刷してあげる・置いてあげる道具。どのページも広告を出しません。

  • くらしのおたすけ

    写経用紙・冷蔵庫に貼る紙・大時計・本物チェックなど。

  • 昭和クイズ・回想法カード

    高齢者向けの 3 択クイズと、折って使う回想法カード。

  • 老眼チェック

    画面の実寸を合わせてから、見え方を確かめます。

  • 年金の繰上げ・繰下げ

    60〜75 歳のどこで受け取るかで年金額を比べます。

  • 高額療養費

    医療費の自己負担の上限と、戻る額を計算します。

すべてのツールは無料・登録不要で、ブラウザだけで動きます。入力したデータはお使いのブラウザ内にだけ保存され、外部に送信されることはありません。
