声でも聞けます。LINE のマイクのボタンを押したまま話して、30秒までで送ってください。聞き取った文を返信の先頭に出します（返信に「聞き取りました」と出ます）。

送った文の扱い

  • ユーザー ID・送った文・返信は保存しません。
  • 保存するのは、今日の件数（返信・AI・声・写真の回数）だけです。
  • メッセージは LINE 社（LY Corporation）のサーバーを通ります。LY株式会社のプライバシーポリシー
  • 読めない文は、質問を読み取るためだけに AI（Cloudflare の Workers AI）に渡すことがあります（返信に「AI が読み取りました」と出ます）。
  • 声は、文字に直すためだけに AI（Cloudflare の Workers AI）に渡します。声は保存しません。
  • 写真は、文字を読んでやさしい日本語に言い換えるためだけに AI（Cloudflare の Workers AI）に渡します。写真・読んだ文・言い換えは保存しません。

答えは目安

  • 答えは目安です。実際の額は、加入している健康保険・日本年金機構・申告の内容などが決めます。
  • 1日の返信が2,000件を超えると、「混んでいます」と返します。声と写真はそれぞれ1日30回までです。
  • 写真の読み取りと言い換えは間違えることがあります。日付と金額は、お知らせの原文で確かめてください。
  • 声の聞き取りは間違えることがあります。返信の先頭の「聞き取りました」の文を確かめてください。
