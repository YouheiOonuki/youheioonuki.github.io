ツールごとの注意事項

ルーレット・くじ引き

抽選結果は、ブラウザの乱数機能を使って決定しています。金銭や重要な権利の分配など、結果に強い公正性が求められる用途には、立会人を置くなど別の方法を併用してください。

傾斜割り勘・飲み会の清算（easy-split）

計算結果は、入力された金額・係数・参加者に基づいて自動で算出したものです。実際の支払い・集金の前に、合計金額がお会計と一致しているかなどを当事者間でご確認ください。計算結果に基づく金銭のやりとりによって生じた損害について、運営者は責任を負いかねます。

メトロノーム

クリック音はブラウザの Web Audio API で鳴らしています。端末やブラウザの状態によってわずかな誤差が生じる場合があります。録音や本番の演奏など、厳密なテンポが求められる場面では専用の機器を併用してください。

イヤホンやヘッドホンで使うときは、音量を下げてから再生し、少しずつ上げて調整してください。大きな音を長時間聴き続けると、耳を傷めるおそれがあります。

社会保険 加入チェッカー

判定と保険料の計算は、公表されている制度（2026年9月時点）をもとにした目安です。実際に加入の対象になるかどうかは、雇用契約の内容や勤務先の状況によって勤務先が判断します。最終的な判断は、勤務先や日本年金機構などの公的機関に確認してください。

天体の位置は計算による近似値です。天体観測の計画などに使う場合は、国立天文台などの公的な情報もあわせてご確認ください。

太陽は絶対に肉眼や双眼鏡・望遠鏡で直接見ないでください。目を傷めます。夜の観察では、足もとや周囲の安全に気をつけ、お子さんは大人といっしょに出かけてください。
