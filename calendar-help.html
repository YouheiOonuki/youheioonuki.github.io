カレンダーに登録する

登録（購読）すると、予定を足したり直したりしたときに、あなたのカレンダーにも入ります。登録は各カレンダーのサービスの中で行い、yorozu-craft に名前やメールアドレスは届きません。

登録できるカレンダー

  • 制度の改定カレンダー（税・社会保険・給付の施行日）：登録する
  • 天文カレンダー（月の満ち欠け・流星群・日食と月食）：登録する

Google カレンダー

パソコンのブラウザで「URL で追加」に上の URL を貼ります。Google カレンダーのアプリ（Android・iPhone）からは登録できません。

手順
  1. パソコンで Google カレンダーを開きます。
  2. ページ左側の［他のカレンダー］の横にある「他のカレンダーを追加」アイコン →［URL で追加］をクリックします。
  3. 上の URL（https:// で始まるほう）を入れ、［カレンダーを追加］をクリックします。
  4. ページ左側の［他のカレンダー］に表示されます。

iPhone

上の「登録する」を押すか、カレンダーアプリの「照会カレンダーを追加」に URL を入れます。

手順と、やめるとき
  1. カレンダーアプリを開き、「カレンダー」ボタンをタップしてから「カレンダーを追加」をタップします。
  2. 「照会カレンダーを追加」をタップし、上の URL を入れて「検索」をタップします。

やめるとき：カレンダーアプリの「カレンダー」ボタン → カレンダーの横の情報ボタン →「登録解除」。

Outlook

Outlook.com で「予定表の追加」→「Web からサブスクライブ」に URL を入れます。反映に 24 時間以上かかることがあります。

手順
  1. Outlook.com にサインインし、左のナビゲーションで予定表を開きます。
  2. 「予定表の追加」（英語の画面では Add calendar）を選びます。
  3. 「Web からサブスクライブ」（Subscribe from web）を選び、上の URL を入れて「インポート」を選びます。
